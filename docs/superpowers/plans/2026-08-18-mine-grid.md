# Mine Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Mine Grid, a responsive Minesweeper-style logic game with three fixed difficulties, first-click safety, meaningful reveal/flag scoring, achievements, and existing Cetus score/leaderboard integration.

**Architecture:** `MineGridGame` extends `BaseGame` and `MineGridRenderer` extends `DOMRenderer`. Mine Grid reuses `shared/grid.ts` for generic grid construction/bounds/search, while `board.ts` owns only mine placement, 8-way adjacency, and flood reveal. Two small core lifecycle seams are added: BaseGame preserves final timer status across `end()`, and an idle-only timer-duration setter lets Mine Grid change difficulty in place instead of replacing game instances.

**Tech Stack:** Astro 5 + TypeScript, Tailwind CSS 4, existing BaseGame/DOMRenderer framework, Vitest/jsdom, Playwright, existing Turso/Kysely score path.

**Spec:** `docs/superpowers/specs/2026-08-18-mine-grid-design.md`

## Global Constraints

- Package manager is **Bun** (`bun@1.3.1`); use `bun run …` for repository scripts.
- Game ID is exactly **`mine_grid`**, route is **`/mine-grid`**, title is **`Mine Grid`**, and icon is **`💣`**.
- Presets are fixed: Easy `8×8 / 8 mines / 180s`, Medium `10×10 / 15 mines / 300s`, Hard `12×12 / 24 mines / 600s`.
- The first accepted reveal must never contain a mine; mines are placed lazily and only the selected cell is excluded.
- No scanner assists, custom board sizes, chording, daily seeds, persistence, solver, or guaranteed no-guess generation.
- Use `BaseGame` + `DOMRenderer`; do not add a handle runtime, mode registry, or generic difficulty manager.
- `GameTimer.setDuration()` and `BaseGame.setDuration()` are idle-only and fail closed while running.
- BaseGame must preserve final remaining/elapsed time across `end()` so existing `getTimerStatus()` consumers see the completed run instead of stopped-timer reset values.
- Configure Mine Grid scoring with `timeBonus: false`; Mine Grid owns its time bonus and awards the whole score only on victory. Mine hit and timeout score `0`.
- Winning score is `max(1, safeCells * 10 + correctlyFlaggedMines * 50 + remainingSeconds * 5 - incorrectFlagActions * 100)`.
- Keep `incorrectFlagActions` as an action-history counter. Do not replace it with final-board wrong flags; a cleared board cannot retain wrongly flagged safe cells.
- All static HTML belongs in `src/pages/mine-grid/index.astro`. TypeScript may create dynamic cell buttons inside `#mine-grid-board` but must not replace Astro-owned parent structure with `innerHTML`.
- `#mine-grid-container` is the initializer's outer-shell guard. `#mine-grid-board` is the renderer container selector.
- Primary click/tap follows Reveal/Flag mode. Desktop `contextmenu` always flags. Hidden cells are semantic buttons with native Enter/Space activation. No arrow-key grid navigation.
- Renderer input uses exactly two delegated container listeners (`click`, `contextmenu`), not per-cell listeners.
- Existing score/API/database contracts are reused. No DB migration and no score/leaderboard endpoint edits.
- Do not add an End Game button. A run ends only by clear, mine hit, or timeout.
- Add the `GAMES` registry entry only after `src/pages/mine-grid/index.astro` exists in the same task.
- `AGENTS.md` is a symlink to `CLAUDE.md`; edit `CLAUDE.md` only.

## Risks

- **Shared timer semantics:** BaseGame final-timer preservation changes post-end `getTimerStatus()` from stopped-timer reset-like values to the actual completed run. Lock manual-end and timeout behavior in core tests and run focused Sudoku, Word Scramble, and Quick Math regressions.
- **Idle duration mutation:** changing duration must never affect a running/paused game. Both GameTimer and BaseGame reject active changes; Mine Grid disables difficulty controls while active.
- **Async score POST:** a new run may start while an older `end()` awaits submission. Reuse the existing `runGuard`; do not add another stale-run system.
- **Random browser board:** Playwright exercises Flag before the first reveal and does not try to solve the random board.

```typescript
import { findCells, inBounds } from '@/lib/games/shared/grid'
import type { GridPosition, MineGridCell } from './types'

export function getAdjacentPositions(
    board: MineGridCell[][],
    row: number,
    col: number
): GridPosition[] {
    const positions: GridPosition[] = []
    for (let dr = -1; dr <= 1; dr++) {
        for (let dc = -1; dc <= 1; dc++) {
            if (dr === 0 && dc === 0) continue
            const nextRow = row + dr
            const nextCol = col + dc
            if (inBounds(board, nextRow, nextCol)) {
                positions.push({ row: nextRow, col: nextCol })
            }
        }
    }
    return positions
}

export function placeMines(
    board: MineGridCell[][],
    mineCount: number,
    safeCell: GridPosition,
    rng: () => number = Math.random
): void {
    const candidates = findCells(
        board,
        (_cell, row, col) => row !== safeCell.row || col !== safeCell.col
    ).map(({ row, col }) => ({ row, col }))

    if (mineCount < 0 || mineCount > candidates.length) {
        throw new RangeError('Invalid Mine Grid mine count')
    }

    for (let i = candidates.length - 1; i > 0; i--) {
        const j = Math.floor(rng() * (i + 1))
        ;[candidates[i], candidates[j]] = [candidates[j], candidates[i]]
    }

    for (const { row, col } of candidates.slice(0, mineCount)) {
        board[row][col].hasMine = true
    }

    for (let row = 0; row < board.length; row++) {
        for (let col = 0; col < board[row].length; col++) {
            if (board[row][col].hasMine) continue
            board[row][col].adjacentMines = getAdjacentPositions(
                board,
                row,
                col
            ).filter(({ row: r, col: c }) => board[r][c].hasMine).length
        }
    }
}

export function getFloodRevealPositions(
    board: MineGridCell[][],
    row: number,
    col: number
): GridPosition[] {
    const start = board[row]?.[col]
    if (!start || start.hasMine || start.flagged) return []

    const queue: GridPosition[] = [{ row, col }]
    const seen = new Set<string>()
    const result: GridPosition[] = []
    let cursor = 0

    while (cursor < queue.length) {
        const current = queue[cursor++]
        const key = `${current.row},${current.col}`
        if (seen.has(key)) continue
        seen.add(key)

        const cell = board[current.row][current.col]
        if (cell.hasMine || cell.flagged) continue
        result.push(current)

        if (cell.adjacentMines === 0) {
            queue.push(...getAdjacentPositions(board, current.row, current.col))
        }
    }

    return result
}

import type { MineGridPreset } from './types'

export function calculateMineGridScore(
    preset: MineGridPreset,
    remainingSeconds: number,
    correctlyFlaggedMines: number,
    incorrectFlagActions: number,
    cleared: boolean
): number {
    if (!cleared) return 0

    const safeCells = preset.rows * preset.cols - preset.mines
    const safeCellPoints = safeCells * 10
    const flagPoints = Math.min(preset.mines, Math.max(0, correctlyFlaggedMines)) * 50
    const timeBonus = Math.max(0, Math.floor(remainingSeconds)) * 5
    const flagPenalty = Math.max(0, incorrectFlagActions) * 100

    return Math.max(1, safeCellPoints + flagPoints + timeBonus - flagPenalty)
}
```
