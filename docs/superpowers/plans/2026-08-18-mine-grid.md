# Mine Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Mine Grid, a responsive Minesweeper-style logic game with three fixed difficulties, first-click safety, reveal/flag controls, scoring, achievements, and existing Cetus score/leaderboard integration.

**Architecture:** `MineGridGame` extends the existing `BaseGame` lifecycle and `MineGridRenderer` extends `DOMRenderer`. Board generation/reveal and scoring stay in pure modules. Because `GameTimer` duration is immutable after construction, `initFramework.ts` replaces only the current idle `MineGridGame` instance when difficulty changes while keeping the renderer and page structure intact.

**Tech Stack:** Astro 5 + TypeScript, Tailwind CSS 4, existing BaseGame/DOMRenderer framework, Vitest/jsdom, Playwright, existing Turso/Kysely score path.

**Spec:** `docs/superpowers/specs/2026-08-18-mine-grid-design.md`

## Global Constraints

- Package manager is **Bun** (`bun@1.3.1`); use `bun run …` for repository scripts.
- Game ID is exactly **`mine_grid`**, route is **`/mine-grid`**, title is **`Mine Grid`**, and icon is **`💣`**.
- Presets are fixed: Easy `8×8 / 8 mines / 180s`, Medium `10×10 / 15 mines / 300s`, Hard `12×12 / 24 mines / 600s`.
- The first accepted reveal must never contain a mine; mines are placed lazily and only the selected cell is excluded.
- No scanner assists, custom board sizes, chording, daily seeds, persistence, solver, or guaranteed no-guess generation in this task.
- Use `BaseGame` + `DOMRenderer`; do not add a new game runtime and do not modify shared `GameTimer` to support mutable duration.
- Configure BaseGame scoring with `timeBonus: false`; Mine Grid awards its entire score only on victory. Mine hit and timeout finish with score `0`.
- Winning score is `max(1, safeCells * 10 + mineCount * 50 + remainingSeconds * 5 - incorrectFlagActions * 100)`.
- All static HTML structure belongs in `src/pages/mine-grid/index.astro`. TypeScript may create dynamic cell buttons inside `#mine-grid-board`, but must not replace Astro-owned parent structure with `innerHTML`.
- Primary click/tap follows the active Reveal/Flag mode. Desktop `contextmenu` always toggles a flag. Hidden cells are semantic buttons and retain native Enter/Space activation. Do not add arrow-key grid navigation.
- Existing score/API/database contracts must be reused. No DB migration and no score/leaderboard endpoint edits.
- Preserve the current `GamePage` convention: the page-level init `<script>` stays outside named slots.
- Do not add an End Game button. A Mine Grid run ends only by clear, mine hit, or timeout.
- `GameTimer.getElapsedTime()` returns `0` after `stop()`. Mine Grid must capture elapsed seconds before delegating to `BaseGame.end()` and must derive that capture from `config.duration - state.timeRemaining`, which also works on the timeout path after `GameTimer` has stopped itself.

```typescript
import type { GridPosition, MineGridCell } from './types'

export function createEmptyBoard(rows: number, cols: number): MineGridCell[][] {
    return Array.from({ length: rows }, () =>
        Array.from({ length: cols }, () => ({
            hasMine: false,
            adjacentMines: 0,
            revealed: false,
            flagged: false,
        }))
    )
}

export function getAdjacentPositions(
    board: MineGridCell[][],
    row: number,
    col: number
): GridPosition[] {
    const positions: GridPosition[] = []
    for (let dr = -1; dr <= 1; dr++) {
        for (let dc = -1; dc <= 1; dc++) {
            if (dr === 0 && dc === 0) continue
            const nextRow = row + dr
            const nextCol = col + dc
            if (
                nextRow >= 0 &&
                nextRow < board.length &&
                nextCol >= 0 &&
                nextCol < (board[nextRow]?.length ?? 0)
            ) {
                positions.push({ row: nextRow, col: nextCol })
            }
        }
    }
    return positions
}

export function placeMines(
    board: MineGridCell[][],
    mineCount: number,
    safeCell: GridPosition,
    rng: () => number = Math.random
): void {
    const candidates: GridPosition[] = []
    for (let row = 0; row < board.length; row++) {
        for (let col = 0; col < board[row].length; col++) {
            if (row !== safeCell.row || col !== safeCell.col) {
                candidates.push({ row, col })
            }
        }
    }
    if (mineCount < 0 || mineCount > candidates.length) {
        throw new RangeError('Invalid Mine Grid mine count')
    }

    for (let i = candidates.length - 1; i > 0; i--) {
        const j = Math.floor(rng() * (i + 1))
        ;[candidates[i], candidates[j]] = [candidates[j], candidates[i]]
    }

    for (const { row, col } of candidates.slice(0, mineCount)) {
        board[row][col].hasMine = true
    }

    for (let row = 0; row < board.length; row++) {
        for (let col = 0; col < board[row].length; col++) {
            if (!board[row][col].hasMine) {
                board[row][col].adjacentMines = getAdjacentPositions(
                    board,
                    row,
                    col
                ).filter(pos => board[pos.row][pos.col].hasMine).length
            }
        }
    }
}

export function getFloodRevealPositions(
    board: MineGridCell[][],
    row: number,
    col: number
): GridPosition[] {
    const start = board[row]?.[col]
    if (!start || start.hasMine || start.flagged) return []

    const queue: GridPosition[] = [{ row, col }]
    const seen = new Set<string>()
    const result: GridPosition[] = []
    let cursor = 0
    while (cursor < queue.length) {
        const current = queue[cursor++]
        const key = `${current.row},${current.col}`
        if (seen.has(key)) continue
        seen.add(key)
        const cell = board[current.row][current.col]
        if (cell.hasMine || cell.flagged) continue
        result.push(current)
        if (cell.adjacentMines === 0) {
            queue.push(...getAdjacentPositions(board, current.row, current.col))
        }
    }
    return result
}

export function countFlaggedCells(board: MineGridCell[][]): number {
    return board.flat().filter(cell => cell.flagged).length
}

export function countIncorrectPreRevealFlags(board: MineGridCell[][]): number {
    return board.flat().filter(cell => cell.flagged && !cell.hasMine).length
}
```

```typescript
import type { MineGridPreset } from './types'

export function calculateMineGridScore(
    preset: MineGridPreset,
    remainingSeconds: number,
    incorrectFlagActions: number,
    cleared: boolean
): number {
    if (!cleared) return 0
    const safeCells = preset.rows * preset.cols - preset.mines
    const clearPoints = safeCells * 10 + preset.mines * 50
    const timeBonus = Math.max(0, Math.floor(remainingSeconds)) * 5
    const flagPenalty = Math.max(0, incorrectFlagActions) * 100
    return Math.max(1, clearPoints + timeBonus - flagPenalty)
}
```

- [ ] **Step 4: Implement reveal, flag, and completion rules**

`revealCell(row, col)` must:

1. reject idle/paused/over/out-of-bounds/revealed/flagged cells;
2. on the first accepted reveal, call `placeMines(board, preset.mines, { row, col }, config.rng)` and then add `countIncorrectPreRevealFlags(board)` once;
3. if the chosen cell is a mine, reveal every mine, set `result = 'mine'`, emit state, and `void this.end()`;
4. otherwise reveal `getFloodRevealPositions(...)`, incrementing `revealedSafeCells` only for newly revealed safe cells;
5. if all safe cells are revealed, set `result = 'cleared'`, calculate the final score from `state.timeRemaining`, add it once via `addScore(score, 'grid_clear')`, emit state, and `void this.end()`;
6. otherwise emit state and return `true`.

`toggleFlag(row, col)` must reject idle/paused/over/out-of-bounds/revealed cells, flip `flagged`, recompute `flagsPlaced`, and increment `incorrectFlagActions` only when placing a new flag on a known safe cell. Before mines are placed, correctness is deferred to the first reveal as described above.

- [ ] **Step 5: Capture elapsed time before BaseGame stops the timer**

Add one private capture:

```typescript
private capturedElapsedTime: number | null = null
```

Override `end()` using the countdown state instead of `GameTimer.getElapsedTime()`:

```typescript
async end(): Promise<void> {
    if (this.state.isActive) {
        this.capturedElapsedTime = Math.max(
            0,
            this.config.duration - this.state.timeRemaining
        )
    }
    await super.end()
}
```

Why this exact form: explicit mine/clear endings still have a running timer, but the timeout path reaches `handleTimeUp()` only **after `GameTimer` has stopped itself**. `duration - state.timeRemaining` is valid for all three outcomes because `onTick` updates `state.timeRemaining` before the timer stops.

Clear the capture in `onGameReset()`:

```typescript
protected onGameReset(): void {
    this.capturedElapsedTime = null
    this.emitStateChange()
}
```

Use the captured value in both stats and game data:

```typescript
private elapsedSeconds(): number {
    return (
        this.capturedElapsedTime ??
        Math.max(0, this.config.duration - this.state.timeRemaining)
    )
}
```

`getGameStats()` returns `timeElapsed: this.elapsedSeconds()` plus the fields in `MineGridStats`.

`getGameData()` returns:
